# AULA 02 : Função console.log()

Nesta aula nos aprendemos um comando JS o consele.log()


- ### A função console.log("Seu Texto") e uma função padrão da linguagem JS e ela imprime dados no terminal do navegador ou no computador pelo node JS.

### E tambem aprendemos um pouco sobre strings que são textos na linguagem JS toda string pode conter letras, numeros, caracteres especiais e etc.

### Exemplo :

```JavaScript
console.log('Ola Mundo!'); // Utilisando Aspas '
console.log("Ola Mundo!"); // Utilizando Aspas "
console.log(`Ola Mundo!`); // Utilizando Acento ` 
```
### Resultado da execução do codigo : 

```JavaScript
Ola Mundo!
Ola Mundo!
Ola Mundo!
```

### Podemos Adicionar Varios dados para serem imprimidos de uma vez só , numeros, expreções boleanas e textos/strings.

```JavaScript
console.log("Olá", ' fulano ', " você tem ", 18, " anos ? ");
```
