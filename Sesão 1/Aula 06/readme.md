# Aula 06

### Nesta Aula Iremos aprender oque são variaveis e pra que elas servem e como criar uma variavel.

### Oque é uma variavel ? é um espaço alocado na memoria do computador utilizado para armazenar informações utilizada pelo codigo e como uma vaixa que posui um  rotulo/nome de identificação , Valor algo dentro, e o tipo de valor que ela tem e as variaveis são variaveis ou seja ela pode mudar seu valores / como tirar alguma coisa dentro da caixa e colocar outra coisa diferente.

### As variaveis são declaradas no nosso codigo da seguinte forma : 

```JavaScript
var nomeDaVariavel = "ValorDaVariavel"; /* A palavra var e o comando para criar uma nova variavel porem ja não é muito utilizada hoje em dia apos essa palavra colocomos o nome da variavel com esse nove que temos acesso ao valor que estiver dentro dela e depois do nome colocamos o sinal de = e o Valor que essa variavel irá receber!*/
let nomeDaVariavel2 = "ValorDaVariavel"; /* A palavra let tambem é utlizada para definir uma nova variavel e é o metodo mais usado hoje em dia para a criação de variavei e logo apos a palavra lat colocamos o nome da variavel depois o sina de = que significa "recebe" e depois o valor que a variavel vai receber! */

```
