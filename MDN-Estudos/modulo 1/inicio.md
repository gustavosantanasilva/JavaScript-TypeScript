# JavaScript

A Linguagem **JavaScript** normalmente abreviada para JS é uma otimizada , interpretada (Significa que a linguagem não possui um compulador que reconstroi o execultavel do codigo toda vez que o codigo é execultado mais execulta todo o codigo novamente). JavaScript é conhecida como linguagem de script para a web entretanto a linguagem tambem e usada em varios outros ambientes alem do navegador como :

- [Node Js](https://nodejs.org/)
- [Apache CouchDB](https://couchdb.apache.org/)
- Adobe Acrobat.

O JavaScript é uma linguagem baseada em multi-paradigmas(Significa que a linguagem surportar diferentes formas de programação / arquiteturas de codigos diferentes e cada paradigma usados em cenarios diferentes)
